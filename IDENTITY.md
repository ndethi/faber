# Identity

## Recommendation: **Faber**

Latin for *craftsman, smith, maker, builder* — the artisan who shapes raw material into something made. It carries the exact "builder/architect" sense you wanted, with two resonances that fit this project:

- *homo faber* — "man the maker," the human as toolmaker and builder.
- *faber est suae quisque fortunae* — "**each person is the architect of his own fortune**." A framework that builds, governed by its maker. On the nose, in a good way.

Short, pronounceable, ownable, and it threads cleanly through the system:

| thing | name |
|---|---|
| product / repo | `faber` |
| orchestrator / CLI | `faber` (e.g. `faber run build.00`) |
| a single build run | an *opus* (work) — optional flourish; `runs/` stays `runs/` |
| the prompt registry | the *codex* — optional; `prompts/` stays `prompts/` |

Tagline option: **Faber — the framework that builds.**

## Shortlist (if you want alternatives)

| name | meaning | feel |
|---|---|---|
| **Faber** ★ | craftsman / smith / maker / builder | grounded, human, "the maker" |
| **Artifex** | master craftsman / creator / artificer | distinctive, evokes mastery |
| **Fabrica** | workshop / construction / a skillfully made thing | good if you want the *platform* named separately from `faber` agents |
| **Opifex** | worker / maker / artificer | rarer, less euphonic |
| **Conditor** | founder / builder / author / establisher | founder-creator vibe |
| **Structor** | builder / mason / one who arranges | solid, less known |

> Applied as the default across the repo identity. To switch, change the product name here and in the repo `README.md` only — the framework artifacts refer to "the framework" generically, so renaming is cheap.
